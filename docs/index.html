PropCourt

Funded-trader firms write the rules and then decide alone whether you broke them. PropCourt pins the rules from the firm's own public page, measures your trade log with plain code, and lets GenLayer validators judge any conduct clause the firm cites. A denial the rules don't back pays out.

Reading the contract…

Three decisions, taken out of the firm's hands

1 · Which rules apply

Every validator reads the firm's rules page and reports each number for that product with a verbatim quote. Code checks the quote is on its own copy of the page. Validators must agree on MATCH / MISMATCH / NOT_STATED for every rule. Then the program is frozen: accounts keep the rules they signed up under.

2 · Whether a number was broken

Plain code measures the closed-trade log: daily P&L on the firm's trading-day clock, worst day, drawdown, best-day share, trading days. If the firm cites a numeric rule that code shows was not broken, the denial is overruled on the spot.

3 · Whether a conduct clause was broken

If the firm cites a pinned clause ("no hedging"), validators judge it from facts computed by code (hedged overlaps, weekend holds, hold times), never the raw log. The burden is on the firm. An unclear answer counts as NOT_SUPPORTED. The losing side gets one appeal.
